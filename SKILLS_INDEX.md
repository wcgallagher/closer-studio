# Skills in this kit

Say what you want in plain words; Claude picks the skill. This list is for curiosity.

## Video
- **reel-editor**: raw clip in, finished 9:16 reel out (cut, captions, hook, end card, clean voice, graded picture).
- **vsl-producer**: long-form sales videos with animated cutaways, checks and a cold review.
- **video-use**: a general video-understanding helper (transcribe, find moments, describe footage).

## Sales
- **closer-mentality**: how we sell. Loaded before any copy or edit.

## Copy
- **longform-copywriter**: long-form sales pages, emails, scripts in direct-response form.
- **trust-scorecard**: scores copy against 20 manipulation tells; we ship at 30 or below.
- **human-tradecraft**: delivery and authority notes for scripts and on-camera lines.

## Core
- **zero-context-auditor**: no skill file or on-screen claim without a source. Run it before editing any skill.
